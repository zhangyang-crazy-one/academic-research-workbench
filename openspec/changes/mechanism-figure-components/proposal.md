## Why
Issue #162 identifies a paper-production gap: bounded composition arranges panels but cannot by itself explain a method's internal operations. The academic-paper figure workflow needs sourced ports, object changes and conditional feedback, with separate semantic and visual evidence.

## What Changes
- Add an independent versioned mechanism facts/figure contract and four bounded component families; retain the existing v1 figure and numeric contracts.
- Resolve mechanism facts through AcceptedRef and compile deterministic editable SVG with explicit input/output ports, expanded innovation and typed relationships.
- Deliver three public synthetic, manually positioned end-to-end examples and a source-answer-based integrity checker, with actual final-size pixels when the optional local rasterizer exists.
- Preserve independent human review as pending. Defer automatic three-strategy search and optional draw.io adapter to the later milestones explicitly proposed in #162; report unsupported status instead of asserting completion.

## Capabilities
### New Capabilities
- `mechanism-figures`: Source-bound mechanism components, deterministic rendering, integrity checks and public acceptance packet.
### Modified Capabilities
None.

## Impact
Python kernel models, research-artifact extension/service/CLI, generated schemas and public fixtures. No new mandatory dependencies, external model calls or vendored source changes. #162 remains open until the later milestones and independent acceptance are complete.
