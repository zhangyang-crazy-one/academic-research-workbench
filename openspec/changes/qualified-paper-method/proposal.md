## Why

Issue #80 asks whether one paper's small, checkable method can become a
bounded research tool. A paper-production experiment plan needs a traceable
algorithm output, but a plausible wrapper or a declared PASS is insufficient
evidence that the code matches the paper or can be safely called. The owner
amendment requires a test receipt before optional MCP registration.

## What changes

- Independently implement Gale–Shapley (1962) deferred acceptance for strict,
  complete equal-sized rankings, with a factual Example 2 golden output.
- Bind paper location/PDF digest, first-party source commit and hashes,
  schemas, empty dependency inventory, environment and actual sandbox tests in
  a source capsule plus local qualification receipt.
- Offer one explicit opt-in MCP server through the shared dual-era stdio
  transport. Failed or missing qualification hides its tool and retains a
  diagnostic; execution is bounded in a network-denied, read-only sandbox.

## Impact and exclusions

This supports a narrow paper-method-to-tool workflow. It does not install
third-party dependencies, redistribute the PDF or author code, load in the
base installation, prove broad market applicability, write the parent ledger,
or automatically accept an algorithm result as scientific evidence.
