## Source and gate

The first commit contains the complete independent implementation, fixture,
schemas and tests. A later capsule pins that immutable commit and the exact
source-file bytes, avoiding a self-referential commit hash. The capsule records
the paper DOI, reviewed PDF digest and page locators, empty dependency
inventory and isolation contract. Local qualification runs the author's
four-by-four reference, deterministic repeat, type/ranking/range rejections,
real network namespace and supervisor timeout probes. It writes a create-only
receipt even on injected test failure. At server startup the same cases are
rerun and checked against the receipt; a declared PASS without actual passing
cases is rejected. Subsequent lists/calls check file and environment drift.

## Runtime boundary

Only the explicit extension launcher imports the optional package. It uses
`arw.mcp_stdio.StdioProtocol` for legacy and modern MCP. `tools/list` returns
one method only after qualification; `tools/call` otherwise returns a protocol
error. Execute runs `/usr/bin/python3 -I -S -B /app/method.py` through `bwrap`
with read-only system standard library and method source, private tmpfs and
network/PID namespaces, clean environment, bounded stdin/stdout and deadline.
No host home or credentials are mounted. A `plan` response has no observed
execution; executed and failed responses carry typed status and digests.

The method proposes deterministically in sorted proposer order, holds the
receiver's highest-ranked proposal and verifies no blocking pair after
termination. It requires complete rankings and caps proposals at `n²`.
The parent, not this tool, owns evidence acceptance and the ledger.
