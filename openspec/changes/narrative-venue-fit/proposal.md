## Why

Authors can validate a manuscript's paper argument yet still lack a reproducible,
bounded comparison with a target venue. Venue prose and learned patterns must not
silently acquire acceptance authority.

## What changes

- Add a read-only `writing narrative-fit` command over an accepted manuscript
  digest, selected narrative, reviewed venue profile, and promoted heuristics.
- Keep official hard requirements, structural realization, empirical patterns,
  and optional reviewer judgment separate in the report.
- Freeze the input and all referenced content for byte-identical offline replay;
  expose current narrative/profile freshness in a separate comparison.
- Return unknown for unevaluated prose rules, bounded anonymity observations,
  and page counts without accepted PDF bytes.

## Impact

The writing extension, state contracts, CLI, checked schemas, focused tests,
and writing runtime documentation change. No model, network request, plan
revision, artifact acceptance, or ledger write is performed.
