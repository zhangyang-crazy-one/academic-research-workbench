## Why

Claim projections and data plots need one accepted-evidence entry point without weakening existing provenance checks. Shared exact arithmetic must remain independent of figure presentation and legacy display receipts.

## What Changes

- Add parent-artifact/project-journal discriminated references and a seven-source adapter matrix preserving original objects and proven scope.
- Add bounded rational arithmetic, sealed expression requests, stable CSV row/group selection, and presentation-independent derivation identities.
- Add read-only fixed-prefix resolution, independent schema snapshots, and realistic ledger fixtures.

## Capabilities

### New Capabilities
- `accepted-ref-numeric-core`: Shared accepted-reference resolution and exact numeric derivations.

### Modified Capabilities
None.

## Impact

New kernel state, ledger, and policy modules; dedicated tests and schemas. No canonical event migration, new authority store, external service, or dependency.
