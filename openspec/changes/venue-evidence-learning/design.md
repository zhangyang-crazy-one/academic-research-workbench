# Design

Accepted exemplar annotations bind an accepted source artifact by SHA-256 and a prior exact accepted source-review artifact. The review declares official URL/DOI, publication category/year, access basis, and reviewer; the annotation records domain/venue, section locators mapped to all six narrative functions, figure roles, and evidence forms. Metadata-only sources cannot claim full-text structure. Duplicate DOI, canonical URL, or source hash cannot add another independent exemplar. An accepted `VenueOutcome` binds its evidence artifact and the authentic narrative snapshot selected for the paper run, plus historically promoted heuristic IDs and prior accepted use artifacts. The existing `learning_observation_recorded` event and body store carry both observations; no new event decoder is needed.

The versioned venue evidence policy names an exact independent exemplar-observation subset. Reviewed sample artifacts classify each exemplar as supporting, counterexample, or unknown. The v2 evaluation receipt records all three counts and FAIL when counterexamples are at least supporting. Historical v1 policies continue to compute mean delta. The ordinary qualification and promotion lifecycle remains in force: no implicit activation, and broader scope still requires cross-project evidence, reviewer approval, and consent.

Applicability describes venue and domain fit independently from approved run/project/domain/global scope. The read-only applicable query exposes only promoted lessons, evidence counts, scope and source links; it never changes a narrative. Phase 2 can consume this result as optional advisory context. Quantity ranges carry explicit nonmandatory status, exception conditions, and counterexample needs. Legacy `style_learning` prose is exported as unverified drafts without an invented exemplar source hash. An accepted legacy profile can be observed, and a selected clause becomes a canonical candidate with zero asserted support and the profile observation in its unknown bucket. Every clause needs explicit nonmandatory guidance review and counterexample needs; quantity ranges additionally use typed guidance when recognized by a reviewer, never inferred from natural-language digits. It cannot evaluate or promote. A successor requires accepting real source bytes and annotation, projecting exemplar observations, and submitting a fresh candidate with genuine coverage.

The additive v2 source-capsule contract distinguishes retained structural-record SHA from reviewed external PDF SHA. It keeps the existing 64 KiB per-artifact limit and requires exact capsule annotations plus prior agent source review at admission and reconstruction. Unknown functions carry no invented locator. Physical PDF digest joins the same identity alias set as v1 source digests, preserving independence across representations. Caller-supplied reviewed audits can be admitted through the ordinary learn observe/import/extract/evaluate/applicable CLI operations. This contract never qualifies, promotes, grants consent, or approves a narrative.

Survey follow-up keeps v1 unchanged and extends v2 full-text access with accepted-author and preprint variants. Non-publisher sources require explicit matching document version, repository authority and relationship note; formal DOI links are declarative metadata and do not certify byte equivalence or settle a disputed venue. A narrowly scoped serializer omits only absent newly added fields, preserving existing capsule bytes. Callers supply reviewed venue and domain classifications; survey observations can record taxonomy, comparison, and bounded open questions without inventing method experiments. Private source comparisons and their supplied classifications remain outside this publication.
