## Context
The four tasks and source digest are committed before generation. Existing numeric admission proves values, not pixels. #152 provides the actual composition backend.
## Goals / Non-Goals
**Goals:** real source-bound SVG, final-size raster output, three structural candidates for loop/mixed tasks, environment/negative evidence and a usable independent review packet.
**Non-Goals:** generic design platform, publisher artwork, paid model calls, automatic scientific/visual acceptance, accessibility certification or cross-host pixel identity.
## Decisions
- Keep synthetic sources/expected objects/relations/values in a frozen JSON file and digest; runner fails on drift. Candidate structure differs by row/column/grid organization, hierarchy and reading path while referencing identical facts.
- Create real canonical runs and accepted sources/numeric children; render via actual artifact services. Preserve the source IR and receipts. Never hand-draw a replacement and label it runtime output.
- Use optional installed system Python GI librsvg/Pango/Cairo in a separate subprocess. Missing renderer/fonts produce unavailable, not PASS. Record actual versions, font paths/content hashes/license metadata, dimensions, raster hashes and a Pango glyph probe. Raster screening measures ink bounds and nonempty pixels; it does not understand the scientific argument.
- Report source/numeric, mechanical, producer argument critique and non-producer human acceptance separately. Stable review binding includes IR/SVG/PNG, raster environment and font hashes. Templates remain pending; changing any bound input expires a completed review. Existing canonical visual review is still parent-admitted, never generated by the benchmark.
- Inject six frozen fault classes and verify their intended detectors. Scientific semantic mismatches are compared with the fixed source inventory; general perception remains independent human work.
## Risks / Trade-offs
- Tiny panels can fail the 7pt author-defined threshold → keep failures and selection reasons visible.
- Pango coverage is a probe, not proof all rendered text is readable → inspect actual PNG and retain human questions.
- Machine fonts affect pixels → record exact font/raster identity and require re-review after drift.
- Human review unavailable during development → deliver the review packet with pending status and keep its acceptance task unchecked.
