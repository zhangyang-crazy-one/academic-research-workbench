<interfaces>
The parent launcher resolves a registered `root_id`, verifies a closed selected generation, opens/passes only that root and generation capability, and starts one process. The process snapshots selected generation identity at initialization; it never follows a changed pointer during a request and never writes root, generation, pointer, database, cache, or temp files. `list_files` sorts by stable file ID/path contract and validates live metadata. `read_file` accepts file_id plus exactly one byte or line range and optional expected_digest; it opens descriptor-relative with no-follow semantics, verifies identity/digest before emitting any body, and returns a bound continuation only for a complete successful chunk.
</interfaces>
