<interfaces>
`arw files root register`, `extraction register`, `sync`, `repair`, and read-only administrative `status` are parent/operator commands, never MCP tools. A root registry maps `root_id` to an absolute configured root plus policy, but persisted query artifacts contain normalized relative paths only. Sync writes `generations/.building-<nonce>/`, closes and hashes every artifact, fsyncs the sibling directory, validates schema/integrity, atomically replaces a small selected-generation pointer, and retains the previous generation. Failure emits a strict receipt outside the candidate without changing the pointer. Native source changes remain ordered patches against the pinned file-base archive.
</interfaces>
