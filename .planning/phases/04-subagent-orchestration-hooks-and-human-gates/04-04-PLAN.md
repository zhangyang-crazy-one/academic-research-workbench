<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| workflow owner/CLI → parent service | Requests can attempt a direct write, unsafe capability, or illegal state transition. |
| execution adapter/attempt root → proposal admission | A process can return malicious bytes, forged observation, or timing-dependent output. |
| crash/recovery → canonical replay | Incomplete work and nonauthoritative trees must not create a false completed state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-19 | Spoofing | CLI/worker authority | mitigate | Route all commands through parent-only runtime methods; evidence provenance cannot become event actor authority. |
| T-04-20 | Tampering | assignment/result lifecycle | mitigate | Freeze digests, validate direct result path/echoes/raw bytes, and append supersession/rejection history. |
| T-04-21 | Repudiation | retries/cancellation/recovery | mitigate | Parent-recorded lifecycle events retain attempt IDs, reasons, deadlines, and observations. |
| T-04-22 | Information disclosure | host transcript | mitigate | Store transcript as scoped observation evidence; canonical payload contains only validated proposal metadata/digests. |
| T-04-23 | Denial of service | dispatch and restart | mitigate | Frozen concurrency, timeout, retry, grace, and orphan budgets with explicit blockers. |
| T-04-24 | Elevation of privilege | CLI/hooks/experiment requests | mitigate | Reject direct journal/reducer access, hook authority, and controlled experiment execution per D-03. |
| T-04-SC | Tampering | package-manager installs | mitigate | No package-manager install is permitted; use the existing offline locked environment. |
</threat_model>
