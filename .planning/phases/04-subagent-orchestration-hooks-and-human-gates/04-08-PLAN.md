## Trust Boundaries

| Boundary | Description |
|---|---|
| test/verifier inputs → technical verdict | Partial, stale, or tampered evidence can create a false green result. |
| sealed corpus → parent evaluator | Evaluation labels must stay out of worker-facing execution. |
| exact stage/host canary → final claim | Source-tree runs, skipped host checks, or credential leakage can invalidate qualification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-43 | Spoofing | technical PASS claim | mitigate | Require signed-by-digest raw evidence, exact stage identity, three qualified hosts, and independent requirement/decision/SC maps. |
| T-04-44 | Tampering | evidence/corpus/stage | mitigate | Owned-root checks, digest inventories, schema validation, tamper tests, and private-path scans. |
| T-04-45 | Repudiation | verifier/task result | mitigate | Record exact commands, sanitized environment/version, output digest, task IDs, and verdict dependencies. |
| T-04-46 | Information disclosure | sealed labels/auth evidence | mitigate | Parent-only sealed evaluator, worker projection leak tests, fresh homes, auth deletion, and redaction. |
| T-04-47 | Denial of service | verifier execution | mitigate | Owned roots, bounded deterministic cases, explicit host-blocked exit, and no retry loop in evidence collection. |
| T-04-48 | Elevation of privilege | verifier/stage | mitigate | Use existing parent/public commands, positive allowlist, no package install, and no release-gate mutation. |
