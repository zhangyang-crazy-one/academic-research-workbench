<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| worker/reviewer/hook evidence → parent event | Untrusted external evidence must not become a writer or a transition. |
| attempt filesystem → manifest intake | A worker-controlled path can contain links, replacements, malformed bytes, or stale output. |
| canonical journal → replay/status | Replayed records must be complete and deterministic without projections. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-07 | Spoofing | canonical actor and source identities | mitigate | Parent-only event authorization plus separate immutable source/host provenance fields. |
| T-04-08 | Tampering | assignment/proposal files | mitigate | Descriptor-safe direct-file checks, immutable digests, path containment, and supersession rules. |
| T-04-09 | Repudiation | lifecycle/gate/human decisions | mitigate | Parent-appended event history, reducer-visible rationale/evidence/actor/scope, and replay tests. |
| T-04-10 | Information disclosure | raw evidence tree | mitigate | Treat raw evidence as nonauthoritative scoped input; status/replay expose only digest-bound approved metadata. |
| T-04-11 | Denial of service | malformed/oversized proposals | mitigate | Frozen byte caps, strict parsing after bounded read, and rejected outcomes without retry amplification. |
| T-04-12 | Elevation of privilege | worker and hook calls | mitigate | Closed workflow authorization rejects all non-parent canonical writes and unauthorized transitions. |
| T-04-SC | Tampering | package-manager installs | mitigate | No package-manager install is permitted; retain the existing lockfile and run offline tests. |
</threat_model>
