<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Codex hook process → parent | Hook stdout and exit status are untrusted convenience signals. |
| hook configuration → installed plugin | Command configuration can attempt shell/write/capability abuse. |
| continuation request → scheduler | A request can amplify work or bypass parent validation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-31 | Spoofing | hook observation | mitigate | Validate event/config digest/subject and classify untrusted observations instead of trusting source process identity. |
| T-04-32 | Tampering | hook configuration/output | mitigate | Strict bounded JSON, exact supported hook config, no shell redirection/write-capable command, and parent revalidation. |
| T-04-33 | Repudiation | hook/continuation outcome | mitigate | Digest-bound observation and parent-recorded accepted/rejected continuation outcome. |
| T-04-34 | Information disclosure | hook runtime environment | mitigate | Do not supply root/control/canonical paths or capability tokens; output contains only scoped metadata. |
| T-04-35 | Denial of service | repeated continuations | mitigate | Per-attempt/per-deliverable counters, bounded stdin, and deterministic duplicate rejection. |
| T-04-36 | Elevation of privilege | hook action | mitigate | Contract and integration tests reject canonical write, proposal admission, gate change, retry ownership, and capability escalation. |
| T-04-SC | Tampering | package-manager installs | mitigate | No package-manager install is permitted; test with the locked offline environment. |
</threat_model>
