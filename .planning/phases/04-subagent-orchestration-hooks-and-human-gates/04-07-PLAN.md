<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| parent adapter → Codex host process | The external process can misreport identity, ignore limits, emit transcript-only output, or survive cancellation. |
| source stage → fresh installed plugin | Repository files and an operator home must not be mistaken for exact installed bytes. |
| authentication material → retained evidence | Fresh-host qualification must not package or record credentials. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-37 | Spoofing | host identity/mapping | mitigate | Accept formal mode only with stable observed host identity and assignment mapping in all three fresh canaries; otherwise BLOCKED. |
| T-04-38 | Tampering | proposal/transcript boundary | mitigate | Parent reads only the direct result file; adapter transcript is observation evidence and cannot become canonical proposal bytes. |
| T-04-39 | Repudiation | host qualification | mitigate | Bind exact installed identity, config digests, command observations, host result, and raw evidence digests in a schema-validated tuple. |
| T-04-40 | Information disclosure | auth/private paths | mitigate | Fresh isolated homes, stage allowlist/private scans, auth deletion, and evidence redaction before retention. |
| T-04-41 | Denial of service | host process | mitigate | Frozen depth/thread/concurrency limits, process group cancellation, grace, qualified force termination, and canary assertions. |
| T-04-42 | Elevation of privilege | host adapter/profile | mitigate | Give host only the immutable assignment/scratch capability; no journal/control root, no canonical writer, and no automatic formal fallback. |
| T-04-SC | Tampering | package-manager installs | mitigate | No package-manager install is permitted; stage the existing locked wheelhouse and use offline verification. |
</threat_model>
