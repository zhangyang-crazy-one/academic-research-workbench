<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| parent scheduler → execution adapter | A host process can lie, time out, complete late, or fail to terminate. |
| independent reviewer → panel synthesis | Reviewer identity and visibility claims are untrusted until policy validation. |
| native hook → parent control plane | Hook output is convenience input and must not become an authorization channel. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-04-13 | Spoofing | host/reviewer identity | mitigate | Treat adapter identity as an observation, require distinct identity proof for formal mode, otherwise return `blocked`. |
| T-04-14 | Tampering | dispatch/result ordering | mitigate | Immutable dispatch spec, bounded raw-result interface, frozen ordering key, and deterministic fake schedules. |
| T-04-15 | Repudiation | panel dissent and hook outcome | mitigate | Structured finding matrix and digest-bound hook observation preserve source evidence and classification. |
| T-04-16 | Information disclosure | blind review envelope | mitigate | Construct isolated reviewer-visible payloads that omit peers, reports, attempts, and synthesis. |
| T-04-17 | Denial of service | task/process lifecycle | mitigate | Fixed concurrency, deadline, grace, retry budget, and late-result classification. |
| T-04-18 | Elevation of privilege | hooks | mitigate | Hook contracts lack canonical write/accept/retry fields and demand parent parity in every status. |
| T-04-SC | Tampering | package-manager installs | mitigate | No package-manager install is permitted; use the existing locked runtime and offline tests. |
</threat_model>
