## Trust Boundaries

| Boundary | Description |
|---|---|
| filesystem segments to accepted event stream | Added/reordered/corrupt segment bytes must not become state. |
| untrusted command request to runtime writer | Caller-controlled identities/payloads cannot select canonical sequence or hashes. |
| concurrent processes to one run | Exactly one process may validate and append against a revision. |
