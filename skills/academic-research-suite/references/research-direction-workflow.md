# Shared research startup and direction contract

Resolve the installed plugin root above `skills/`. Read
`docs/runtime/research-direction-workflow.md` beneath that root for the shared
`research start/status/resume`, external-package, intake, operationalization,
parent admission and offline walkthrough contract. Use that same document
from either main skill; do not create a second authority or weaken the original
ARS validators. Candidate hypotheses and broad directions do not select a paper
narrative. Source/version changes require review, never automatic conclusion
upgrades. Hooks are observational and canonical evidence remains parent-owned.
