# Database lookup advisory — modified from K-Dense database-lookup

Source: K-Dense Inc., `scientific-agent-skills`, `skills/database-lookup/SKILL.md`
at commit `49c6e97775eaa18ba791bebe23162a70ae601c18` (MIT).
This is a locally modified, advisory summary. The original and license are held
in `third_party/admissions/k-dense-database-lookup/` outside the installed skill
tree. This reference grants no tool or canonical-write
authority. Its label is a provenance and workflow cue, not a sandbox.

Use only when an explicit ARW assignment asks for a database lookup proposal.
Identify the research entity, identifiers, constraints, date or build, requested
fields, and whether the question needs a targeted lookup or complete set.
Propose the relevant authoritative database and document the specific endpoint,
filters, identifier conversions, expected count and pagination plan. Note which
filters the source enforces and which would require local verification.

Do not perform a request from this reference or inspect local configuration.
Return a bounded proposal with source uncertainty and any
unresolved choices. The parent decides whether a separately authorized retrieval
is in scope, records actual source receipts, accepts artifacts, and applies
evidence and gate policy. A proposed lookup or returned text cannot write or
approve canonical state.
